# 402Lab brand

![Every 402Lab logo variant on dark and light backgrounds](brand-sheet.png)

The logo is a lab flask holding lime liquid, next to the wordmark "[402] Lab". The "402" sits in a thin rounded box, a nod to HTTP 402 Payment Required. Every file here is a vector master with the text converted to paths, so no font install is needed.

## Variants

| Variant           | Files                                                                      | Use it for                                                    |
| ----------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Stacked (primary) | `logo-stacked-dark.svg`, `logo-stacked-light.svg`                          | README, slides, title screens, t-shirt front.                 |
| Horizontal        | `logo-horizontal-dark.svg`, `logo-horizontal-light.svg`                    | Headers, footers, banners and any wide, short slot.           |
| Wordmark          | `wordmark-dark.svg`, `wordmark-light.svg`                                  | When the flask already appears nearby.                        |
| Mark              | `logo-mark-flask.svg`                                                      | Avatars, stickers, slide corners. No tile.                    |
| Mark on tile      | `logo-mark.svg`                                                            | In-app logo, social avatars, 64px and up.                     |
| Simplified mark   | `logo-mark-simplified.svg`                                                 | 32px to 63px. One lime bubble, stroke 4.5.                    |
| Favicon           | `favicon.svg`, `logo-mark-favicon.svg`, `favicon.ico`, `favicon-16/32.png` | Under 32px. No bubbles, thick stroke.                         |
| App icon          | `logo-app-icon.svg`, `app-icon-1024.png`, `app-icon-512.png`               | Store listings and home screens. 19% padding inside the tile. |
| One color         | `logo-*-1color-white.svg`, `logo-*-1color-black.svg`                       | Embossing, laser, fax, single ink printing.                   |
| Screen print      | `logo-print-2color.svg`                                                    | Dark t-shirts. Two inks: lime and white.                      |

Pick dark files for dark backgrounds and light files for light backgrounds.

## Colors

| Role                          | Hex                 |
| ----------------------------- | ------------------- |
| Lime, liquid and "402"        | `#B6F23A`           |
| Deep lime, "402" on light     | `#4D7C0F`           |
| Ink on dark, flask and "Lab"  | `#E8EAED`           |
| Ink on light, flask and "Lab" | `#14171C`           |
| Tile and bubbles              | `#14171C`           |
| Tile border                   | `#262B33`           |
| Box outline                   | lime at 70% opacity |

The liquid stays lime on light backgrounds too. In one-color files the "402" box turns into a solid shape with the digits cut out, and the bubbles are cut out of the liquid. The screen print file uses full-strength lime for the box, so it needs no halftone.

## Typography

"402" is JetBrains Mono SemiBold. "Lab" is Space Grotesk Bold. Both are already outlined in the files. Use the same two fonts for headlines next to the logo.

## Clear space

Keep empty space around the logo at least as tall as the flask on every side. Nothing else enters that area: no text, no edges, no other logos.

## Minimum size

- Stacked: 120px wide on screen, 25mm wide in print.
- Mark: 24px on screen, 6mm in print. Below 32px use the favicon file.

## Do

- Use the files as they are, scaled proportionally.
- Use the light files on white or pale backgrounds and the dark files on dark ones.
- Use the one-color files when only one ink is available.

## Don't

- Don't recolor, stretch, rotate or add shadows and glows.
- Don't retype the wordmark in another font.
- Don't put the full-color logo on busy photos or on lime.
- Don't drop the box around "402" or change the order of "402" and "Lab".
- Don't use the bubble version below 32px. It turns into noise.
